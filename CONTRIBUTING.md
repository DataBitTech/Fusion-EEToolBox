# Contributing to Electronics Extended Toolbox

Thank you for considering contributing to the Electronics Extended Toolbox! This project welcomes contributions from the community to improve and extend its functionality.

## How to Contribute

### Reporting Bugs

If you find a bug, please create an issue with the following information:
- A clear, descriptive title
- Steps to reproduce the issue
- Expected and actual behavior
- Fusion 360 version and operating system details

### Suggesting Features

Have an idea for a new feature? Please create an issue describing:
- What the feature should do
- Why it would be useful
- Any implementation considerations

### Pull Requests

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes with clear, descriptive commit messages
4. Ensure code follows project coding standards
5. Add or update documentation as needed
6. Submit a pull request

## Development Guidelines

### Code Standards

- **Python**: Follow PEP 8 style guidelines
- **JavaScript**: Follow ES6+ best practices
- **HTML**: Use semantic HTML elements

### Project Structure

Please refer to [DEVELOPER_GUIDE.md](DEVELOPER_GUIDE.md) for the project structure and code organization guidelines.

### Testing

Before submitting a pull request, ensure that your code doesn't break existing functionality

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct:
- Be respectful and inclusive
- Provide constructive feedback
- Focus on the best outcomes for the community

## Questions?

If you have questions about contributing to this project, please open an issue.
